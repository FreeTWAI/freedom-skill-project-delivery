# Sprint Milestone Progression

This document defines the standard milestones for a sprint lifecycle.

## 1. Sprint Planning
- Define sprint goals.
- Select backlog items for the sprint.
- Break down items into tasks and estimate effort.

## 2. Sprint Execution
- Daily stand-ups to discuss progress and blockers.
- Continuous development and testing.
- Regular updates to task boards.

## 3. Sprint Review
- Demonstrate completed work to stakeholders.
- Gather feedback.
- Assess what was "Done" vs "Not Done".

## 4. Sprint Retrospective
- Review what went well.
- Identify areas for improvement.
- Create action items for the next sprint.
